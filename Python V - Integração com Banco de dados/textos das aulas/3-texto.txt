🎬 Aula: Inserindo dados na tabela do banco de dados:

- Conectar ao banco de dados title.db com sqlite3.connect.

- Criar um cursor para executar comandos SQL.

- Inserir registros na tabela movies:

- Adicionou três filmes com nome, ano e nota:

- Super Mario Bros (2023, nota 10)

- Avatar (2023, nota 9.5)
