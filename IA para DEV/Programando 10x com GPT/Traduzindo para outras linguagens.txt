Após compreender o funcionamento do código Python, utilizamos o Copilot para gerar uma versão equivalente em JavaScript.

Prompt utilizado:

"Copilot, traduza o seguinte jogo de adivinhação de Python para JavaScript. O jogo deve gerar um número aleatório entre 0 e 100, permitir que o jogador insira palpites via prompt(), oferecer níveis de dificuldade, contar tentativas e permitir reiniciar o jogo. Mantenha a lógica e funcionalidade do original, adaptando para sintaxe JavaScript."

🔹 Código Traduzido para JavaScript:

```javascript
const chooseDifficulty = () => {
  const difficulty = prompt('Escolha a dificuldade: fácil, médio ou difícil.');
  switch (difficulty.toLowerCase()) {
    case 'fácil':
      return 10;
    case 'médio':
      return 5;
    case 'difícil':
      return 3;
    default:
      alert('Dificuldade não reconhecida. Configurando para "fácil".');
      return 10;
  }
};

const isValidGuess = (guess) => {
  const number = parseInt(guess, 10);
  return !isNaN(number) && number >= 0 && number <= 100;
};

const processGuess = (guessNumber, secretNumber, attempts, maxAttempts) => {
  if (guessNumber < secretNumber) {
    alert('Baixo. Tente um número maior.');
  } else if (guessNumber > secretNumber) {
    alert('Alto. Tente um número menor.');
  } else {
    alert(`Correto! O número é ${secretNumber}. Você acertou em ${attempts} tentativas.`);
    return true;
  }

  if (attempts === maxAttempts) {
    alert(`Suas tentativas acabaram! O número era ${secretNumber}.`);
  }

  return false;
};

const askPlayAgain = () => confirm('Você deseja jogar novamente?');

const playGame = () => {
  const maxAttempts = chooseDifficulty();
  const secretNumber = Math.floor(Math.random() * 101);
  let attempts = 0;
  let isCorrect = false;

  while (!isCorrect && attempts < maxAttempts) {
    const guess = prompt(`Digite um número entre 0 e 100. Tentativa ${attempts + 1} de ${maxAttempts}:`);
    attempts += 1;

    if (isValidGuess(guess)) {
      const guessNumber = parseInt(guess, 10);
      isCorrect = processGuess(guessNumber, secretNumber, attempts, maxAttempts);
    } else {
      alert('Por favor, insira um número válido entre 0 e 100.');
    }
  }

  if (askPlayAgain()) {
    playGame();
  }
};

playGame();
```
