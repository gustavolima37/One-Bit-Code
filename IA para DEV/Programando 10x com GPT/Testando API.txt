🔹 Introdução ao Postman

O Postman é uma ferramenta essencial para desenvolvedores que trabalham com APIs. Ele permite:

- Enviar requisições HTTP (GET, POST, PUT, DELETE)
- Visualizar respostas e status
- Organizar endpoints em coleções
- Automatizar testes e validar comportamentos

🔹 Passo 2: Código da API com FastAPI (comentado)

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List
from uuid import uuid4

app = FastAPI()

# Modelo de dados do imóvel
class Property(BaseModel):
    title: str
    description: str
    price: float
    type: str
    address: str
    bedrooms: int
    bathrooms: int
    area: float

# Lista mockada
properties: List[dict] = []

# POST /properties - Criação de imóvel
@app.post("/properties")
def create_property(property: Property):
    new_property = property.dict()
    new_property["id"] = str(uuid4())  # Gera ID único automaticamente
    properties.append(new_property)
    return new_property

# GET /properties - Lista todos os imóveis
@app.get("/properties")
def get_properties():
    return properties

# GET /properties/{property_id} - Busca imóvel por ID
@app.get("/properties/{property_id}")
def get_property(property_id: str):
    for prop in properties:
        if prop["id"] == property_id:
            return prop
    raise HTTPException(status_code=404, detail="Imóvel não encontrado")

# PUT /properties/{property_id} - Atualiza imóvel por ID
@app.put("/properties/{property_id}")
def update_property(property_id: str, updated: Property):
    for index, prop in enumerate(properties):
        if prop["id"] == property_id:
            updated_data = updated.dict()
            updated_data["id"] = property_id  # Mantém o ID original
            properties[index] = updated_data
            return updated_data
    raise HTTPException(status_code=404, detail="Imóvel não encontrado")

# DELETE /properties/{property_id} - Remove imóvel por ID
@app.delete("/properties/{property_id}")
def delete_property(property_id: str):
    for prop in properties:
        if prop["id"] == property_id:
            properties.remove(prop)
            return {"message": "Imóvel removido com sucesso"}
    raise HTTPException(status_code=404, detail="Imóvel não encontrado")
```

🟢 Para executar:
```bash
uvicorn nome_do_arquivo:app --reload
```
(Substitua `nome_do_arquivo` pelo nome real do seu arquivo Python)

🔗 Acesse a documentação interativa gerada automaticamente:
```
http://localhost:8000/docs
```

🔹 Passo 4: Importando o JSON no Postman

1. No Postman, clique em **Import**  
2. Selecione **Raw Text**  
3. Cole o JSON gerado pela IA  
4. Clique em **Continue** e depois em **Import**

🔹 Passo 5: Testando os Endpoints

- **POST**: Crie um novo imóvel com os dados no corpo da requisição  
- **GET**: Liste todos os imóveis ou consulte um específico por ID  
- **PUT**: Atualize um imóvel existente informando o ID e os novos dados  
- **DELETE**: Remova um imóvel informando o ID na URL
