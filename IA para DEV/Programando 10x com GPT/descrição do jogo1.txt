# 🎮 Jogo de Adivinhação com Python + Copilot

Este mini projeto demonstra como utilizar **Inteligência Artificial assistiva** com o **Copilot da Microsoft** para acelerar o desenvolvimento de software. O objetivo é criar um jogo simples de adivinhação em **Python puro**, executado no terminal, com suporte da IA para geração e refatoração de código.

---

## 📌 Descrição do Projeto

Neste jogo, o computador escolhe aleatoriamente um número entre 0 e 100, e o jogador deve tentar adivinhar qual é. A cada tentativa, o programa informa se o palpite foi **muito alto**, **muito baixo** ou **correto**. O jogo continua até o jogador acertar, e ao final, exibe o número total de tentativas.

Este projeto foi desenvolvido com o apoio do **Copilot**, que auxiliou na geração do código base, estruturação lógica e sugestões de melhorias — demonstrando como ferramentas de IA podem ser integradas ao fluxo de trabalho de um desenvolvedor.

---

## 🧠 Tecnologias Utilizadas

- **Python 3.x**  
- **Copilot (IA assistiva)**  
- **Terminal / Console**  

---

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/jogo-adivinhacao-python-copilot.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd jogo-adivinhacao-python-copilot
   ```

3. Execute o jogo:
   ```bash
   python jogo_adivinhacao.py
   ```

4. Ou copie e cole o codigo no seu terminal (vscode)

## 🧪 Funcionalidades

- Geração de número aleatório entre 0 e 100  
- Entrada de dados via `input()`  
- Feedback interativo sobre o palpite  
- Contador de tentativas  
- Tratamento de erros para entradas inválidas
