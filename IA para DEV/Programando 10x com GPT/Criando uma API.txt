1️⃣ Principais Campos de um Imóvel

Antes de codificar, é importante entender os campos que descrevem um imóvel:

- `id`: Identificador único do imóvel  
- `title`: Título do anúncio  
- `description`: Descrição detalhada  
- `price`: Preço  
- `type`: Tipo do imóvel (casa, apartamento, etc.)  
- `address`: Endereço  
- `bedrooms`: Número de quartos  
- `bathrooms`: Número de banheiros  
- `area`: Área em metros quadrados

4️⃣ Código Gerado pela IA com FastAPI

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List
from uuid import uuid4

app = FastAPI()

# Modelo de dados
class Property(BaseModel):
    id: str
    title: str
    description: str
    price: float
    type: str
    address: str
    bedrooms: int
    bathrooms: int
    area: float

# Lista mockada
properties: List[Property] = []

# Create
@app.post("/properties", response_model=Property)
def create_property(property: Property):
    property.id = str(uuid4())  # Gera ID automaticamente
    properties.append(property)
    return property

# Read all
@app.get("/properties", response_model=List[Property])
def get_properties():
    return properties

# Read by ID
@app.get("/properties/{property_id}", response_model=Property)
def get_property(property_id: str):
    for prop in properties:
        if prop.id == property_id:
            return prop
    raise HTTPException(status_code=404, detail="Imóvel não encontrado")

# Update
@app.put("/properties/{property_id}", response_model=Property)
def update_property(property_id: str, updated: Property):
    for index, prop in enumerate(properties):
        if prop.id == property_id:
            updated.id = property_id  # Mantém o ID original
            properties[index] = updated
            return updated
    raise HTTPException(status_code=404, detail="Imóvel não encontrado")

# Delete
@app.delete("/properties/{property_id}")
def delete_property(property_id: str):
    global properties
    properties = [p for p in properties if p.id != property_id]
    return {"message": "Imóvel removido com sucesso"}
```
